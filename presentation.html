문제의 본질

다한증 사용자는 단순히 터치가 어려운 것이 아니라,

"내가 제대로 조작했는지
확신하지 못하는 불안"을

반복적으로 경험한다.

모든 단계에 "확신 부족"이 끼어들어 흐름을 끊는다. 이것이 이 앱이 해결해야 할 단 하나의 문제다.

방향 수정

교수님 피드백 반영

▼ 피드백
너무 솔루션에 맞춰져 있다
→ 페르소나(불안·확신)에 초점을 다시 맞춤
▼ 피드백
실패 과정을 굳이 흐름에 넣을 필요가 있나
→ 실패 시나리오 제거. 처음부터 성공 경험 우선

팀 내부 확정 결정

  • 롱프레스 전면 제거 → 슬라이드 확인 방식으로 대체 (게이지 + 햅틱)
  • 자동 보호모드 제거 → 사용자가 직접 켜는 "간단 모드"로 변경 ('보호 모드' 명칭 금지)
  • 인증 선택형 → 첫 설정에서 지문 / Face ID / 패턴 중 기본값 선택
  • 위젯 마스킹 → 롱프레스 대신 터치 1회 토글

Solution 1

Solution 1 Anger ↓ Trust ↑

터치 안정성 UI

  • 버튼 최소 56px, 간격 최소 16px — 오터치 방지
  • 주요 액션 버튼을 오른쪽 가장자리에 배치, 좌측 하단 금지
  • 뒤로가기: 상단 좌측 고정 + 0.3초 확인 하이라이트
  • 키패드 중복 입력 방지: 250ms 디바운스 + 흔들림 모션
  • 금액 옆 한글 보조 표기 ("오십만 원") — 오인 방지

  • 입금 수신: 위젯 🎁 선물상자 + 흔들림 애니메이션
