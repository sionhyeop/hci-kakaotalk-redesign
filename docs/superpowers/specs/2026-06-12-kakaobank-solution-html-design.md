# 카카오뱅크 솔루션 HTML 설계서

- 날짜: 2026-06-12
- 산출물: `카카오뱅크_솔루션.html` (단일 파일, 바닐라 JS)
- 베이스: `카카오뱅크_클론_고해상도.html` (1523줄, 폰 프레임 390×802, 템플릿 문자열 기반 화면 시스템)
- 근거 문서: presentation.html(git ea88be8)의 Solution 1~4, CLAUDE.md 화면 명세

## 확정된 방향 (사용자 승인)

1. **비주얼: 카카오뱅크 룩 100% 유지.** 노란색 포함 기존 클론 스타일 그대로. 독자 팔레트(네이비/민트) 사용하지 않음. "실제 카뱅에 이 기능이 들어간다면"이라는 톤.
2. **화면 범위: 클론 전체 유지 + 솔루션 추가.** 혜택/투자/AI상담/전체메뉴 등 시연 무관 화면도 그대로 둔다.
3. **구현 방식: 인플레이스 강화(접근 A).** 이체 플로우 화면 자체를 솔루션 버전으로 강화. before/after 토글 없음.

## 페르소나 연결

극심한 손 다한증을 가진 24세 '김진우'. 핵심 목표는 빠른 송금이 아니라 **"제대로 보냈다는 확신"**. 사용자명을 김범수 → **김진우**로 변경한다(계좌·거래 더미 데이터는 클론 것 유지).

## 변경/추가 명세

### 1. 진입 플로우 — Solution 4 (홈 위젯 + 마스킹)

- 첫 화면을 패턴 잠금 → **폰 잠금화면 모사 + 홈 위젯 카드**로 교체. (기존 패턴 화면 코드는 인증 선택의 패턴 수단에서 재활용)
- 위젯 기본 상태: 잔액 `●●●,●●●원`, 최근 거래 상대 `박●훈`, 거래 시간 표시
- 마스킹 영역 탭 1회 → 언마스킹, **5초 후 자동 재마스킹**, 남은 시간 얇은 프로그레스 링 표시
- 언마스크 상태에서 `계좌 복사` 버튼 노출 → 클립보드 복사 + "복사됨" 토스트 + 햅틱
- 입금 발생 시(데모 패널 트리거) 위젯에 🎁 선물상자 + 흔들림 애니메이션 → 탭하면 입금 상세로
- 위젯 본체 탭 → 인증 화면 진입

### 2. 인증 화면 — 선택형, 실패 없음

- 첫 진입 시 **지문 / Face ID / 패턴** 카드 3개 중 선택. 선택은 기본값으로 저장(localStorage), 이후 진입 시 해당 수단 화면으로 바로
- 어떤 수단이든 탭(패턴은 4점 이상 드로잉) → **1초 성공 애니메이션**(체크 모션 + 햅틱) → 홈
- **실패 플로우 없음** (지문 실패 → 다른 수단 전환 같은 시나리오 만들지 않음)

### 3. 홈 화면 강화

- 우측 상단 `간단 모드` 토글 스위치
- 잔액 카드 금액에 마스킹 탭 토글(위젯과 동일 규칙: 탭 → 5초 후 재마스킹)
- 우측 하단 큼직한 `보내기` FAB(카뱅 노란색, 최소 56px) → 받는사람 화면 직행

### 4. 송금 플로우 강화 — Solution 1 + 2 (하이라이트)

- **받는사람**: 최근 송금 상대를 큰 카드 그리드(2열)로 상단 배치. 기존 리스트는 하단 보조
- **금액 입력**:
  - 키패드 키 높이 64px 이상, 키 간 간격 12px 이상
  - **중복 입력 방지**: 동일 키 250ms 이내 재입력 무시 + 해당 키 흔들림 모션 + "한 번만 입력됐어요" 마이크로 라벨(무시 사실을 숨기지 않음). 백스페이스에도 동일 적용
  - 입력 금액 초대형 표시 + **한글 보조 표기**("오십만 원") — 자릿수 오인 방지
  - 키 입력마다 햅틱 10ms + 키 펄스
- **확인 단계**: 기존 "이체하시겠습니까?" 시트의 [취소/이체하기] 버튼 → **슬라이드 투 센드 바**로 교체. 받는 사람·은행·금액(숫자+한글) 카드 재표시. 우측 끝까지 밀면 송금(게이지 차오름 + 색 변화), 중간에 놓으면 부드럽게 복귀. 완료 순간 강한 햅틱(50ms) + 화면 확산 모션
- **완료 화면**: 큰 체크 애니메이션 + 진동, "김진우님, ○○○님께 50,000원을 **정확히** 보냈어요", **보낸 시각 초 단위** + 상태 "완료" 강조 카드, 우측 하단 `홈으로` + 그 위 `영수증 보기`

### 5. 거래내역 카드 스택 + 볼륨 버튼 — Solution 3 일부

- 계좌 상세에서 진입하는 **카드 스택 뷰**: 거래 1건씩 크게(상대·금액·시각·상태 체크)
- **폰 프레임 좌측에 볼륨키 모양 UI** 렌더. 클릭 또는 키보드 ↑↓로 카드 넘김 — "터치 없이 재확인" 컨셉

### 6. 간단 모드 — Solution 3

- 홈 우측 상단 토글로 사용자가 직접 on/off. **자동 진입 절대 없음**
- 켜면 `보내기 / 잔액 / 거래내역` 초대형 버튼 3개 레이아웃으로 전환(레이아웃 모션 포함)
- 간단 모드의 송금: 최근 상대 4명 카드 + 키패드 + 슬라이드만으로 압축
- 명칭 **"간단 모드"** 고정 ('보호 모드' 금지)

### 7. 공통 인터랙션 규칙

- 뒤로가기: 상단 좌측에만. 탭 시 **0.3초 확인 하이라이트 후 이동**. 하단 뒤로가기 금지
- 주요 액션 버튼은 우측 하단~우측 가장자리. 좌측 하단 액션 버튼 금지
- 시연 동선 화면의 버튼 최소 56px, 간격 최소 16px (시연 무관 클론 화면은 원본 밀도 유지)
- 모든 탭 요소 3중 피드백: 시각(눌림+링 확산) + 햅틱(`navigator.vibrate(10)`) + 마이크로 모션. 햅틱 미지원 환경은 화면 펄스로 폴백
- **롱프레스 전면 금지**

### 8. 데모 패널 (프레임 바깥 데스크톱 영역)

- `입금 발생시키기`: 위젯 🎁 + 흔들림 트리거
- `중복 입력 시뮬레이션`: 금액 키패드에서 같은 키 2연타 자동 재생 → 방지 동작 시연
- 햅틱 발생 시 폰 프레임 테두리 펄스(데스크톱 가시화)

## 완료 기준 (DoD)

1. 잠금화면 위젯 → 인증 → 홈 → 송금(받는사람→금액→확인 슬라이드) → 완료 → 거래내역 재확인까지 끊김 없이 시연 가능
2. 중복 입력 방지가 실제 동작하고 라벨로 안내됨
3. 슬라이드 투 센드 게이지·완료 햅틱·체크 애니메이션이 부드럽게 동작
4. 간단 모드 토글 전환 모션 동작
5. 위젯 마스킹 토글 + 5초 재마스킹 + 계좌 복사 동작
6. 데스크톱(폰 프레임)과 390px 모바일 뷰포트 모두 깨지지 않음
7. 기존 클론 화면(혜택/투자/AI 등)이 그대로 동작
