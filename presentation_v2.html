앱 선정 배경

카카오뱅크는 별도 지점 방문 없이 계좌 개설·이체·대출·카드 관리 등 대부분의 금융 업무를 모바일에서 처리하게 해 주는 인터넷전문은행 앱입니다.

기존 시중은행 앱에 비해 프로세스를 단순화하고, 친숙한 디자인과 메시지 중심 인터랙션으로 "쉽고 간편한 은행 경험"을 제공하며 금융 접근성을 크게 높여 왔습니다.

중요성

하지만 금융 업무 특성상 작은 실수도 금전적 피해로 이어질 수 있기 때문에, "쉽다·편하다"뿐 아니라 실수 방지·안전성·신뢰감이 매우 중요한 서비스입니다.

하루에 10번 정도는 닦는 것 같고, 카카오뱅크에서 송금을 실수할 때 짜증이 난다.

Q1. 하루 평균 스마트폰 화면을 타월이나 옷에 닦는 횟수는 어느 정도입니까?

두 문장에 한 번씩은 틀리는 것 같고, 대체 수단도 터치를 해야 해서 땀을 제대로 닦지 않으면 대부분 오타가 발생한다.

Q2. 지문 인식 실패 시, 대체 수단(비밀번호/패턴) 입력 과정의 오타율은 어느 정도입니까?

송금이 금액을 설정하다가 틀리는 경우가 있어서 더 번거롭다.

Q3. '잔액 확인'과 '송금' 중 어느 쪽에서 터치 조작의 번거로움이 더 크게 다가옵니까?

발견 과정

팀 내에 카카오뱅크를 쓰는 팀원들을 조사하던 도중 공통적으로 "다한증"을 가진 유저들을 발견했습니다.

팀원들을 대상으로 질문지를 작성한 뒤 인터뷰를 진행하고, 공통적인 이슈를 파악했습니다.

SOLUTION 1 / 4

터치 안정성 UI

Anger ↓ · Trust ↑ — input that lands exactly as intended

  • 버튼 최소 56px, 간격 최소 16px — 인접 오터치 방지
  • 주요 액션 버튼을 오른쪽 가장자리(엄지 도달 영역)에 배치 — 터치 성공률이 높은 영역 활용
  • 오터치 가능성이 높은 영역(뒤로가기 등)은 최소화하고 상단으로 이동
  • 숫자 키패드 중복 입력 방지 — 동일 키 연속 입력 디바운스 + "한 번만 입력됐어요" 피드백
  • 금액 입력 시 한글 보조 표기("오십만 원") — 50,000 vs 500,000 오인 방지

SOLUTION 2 / 4

조작 성공 피드백 강화

Fear ↓ · Trust ↑ · Calm — every action answers back "done"

  • 키 입력마다 즉각적인 햅틱 + 시각 피드백 — "눌렸다"는 확신을 매 터치마다 제공
  • 송금 확정은 슬라이드 투 센드 — 게이지 차오름 애니메이션 + 완료 시 강한 진동
  • 완료 화면에서 거래 정보(받는 사람·금액·시간) 강조 — 재확인 욕구를 화면 안에서 해소
  • 입금 수신 시 위젯에 선물상자 표시 등 명확한 수신 피드백

SOLUTION 3 / 4

선택형 간단 모드

Disgust ↓ · Joy · Simple — fewer targets, bigger targets, user's choice

  • 핵심 기능(송금·잔액·거래내역)만 남긴 큰 버튼 중심 인터페이스
  • 자동 개입 없이 사용자가 토글로 직접 선택 — 시스템의 갑작스러운 개입은 새로운 불안이 됨
  • 일반 모드 ↔ 간단 모드 전환 자유 — 다른 기능이 필요할 때의 트레이드오프 해소
  • 거래내역 넘기기 등 단순 재확인 동작에 물리 버튼(볼륨키) 활용 — 터치 없는 조작 경로 확보
  • 명칭은 "간단 모드" — '보호 모드'는 낙인 우려로 배제

SOLUTION 4 / 4

홈 위젯 + 마스킹

Anticipation · Trust · Optimistic — reassurance without entering the app

  • 앱 진입 없이 잔액 · 최근 거래 상대 · 거래 시간 바로 확인
  • 기본 마스킹 처리 — 공공장소에서의 개인정보 노출 부담 해소
  • 터치 1회 → 짧게 표시 → 자동 재마스킹 — 롱프레스 없는 안전한 확인
  • 마스킹 해제 상태에서 바로 계좌번호 복사
  • 반복 재확인 피로 ↓ — "앱에 다시 안 들어가도 된다"는 편안함 제공
